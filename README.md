## ✨ Features

- 🎨 Material You Design & Dark mode
- 📦 Sandboxed Workspace agent environment
- 🔄 Focused AI Providers: OpenAI, Google Gemini, DeepSeek, OpenRouter, Vercel, xAI
- 🔍 Unified Search integrations: Bing, Tavily, Exa, SearXNG, Brave, Ollama, Perplexity, Firecrawl, Grok, Custom JS
- 🛠️ MCP (Model Context Protocol) support
- 📝 Markdown Rendering with syntax highlighting, LaTeX formulas, and tables
- 🪾 Branching conversation tree & regeneration
- 🧠 Memory & persistent assistant behaviors

## 🛠️ Development

Built with modern Android standards:
- [Kotlin](https://kotlinlang.org/)
- [Jetpack Compose](https://developer.android.com/jetpack/compose) & Material Design 3
- [Koin](https://insert-koin.io/)
- [DataStore](https://developer.android.com/topic/libraries/architecture/datastore) & [Room](https://developer.android.com/training/data-storage/room)
- [OkHttp](https://square.github.io/okhttp/) & [kotlinx.serialization](https://github.com/Kotlin/kotlinx.serialization)

```bash
./gradlew assembleDebug
./gradlew test
```
